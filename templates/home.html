Cyber Security and Networking Project

Welcome to Cyber Proxy Defender, a project built to monitor, filter, and understand network traffic.

This project demonstrates how a proxy server can sit between users and websites to improve security. It captures traffic activity, blocks suspicious destinations, stores request logs, and gives admins one dashboard for visibility, decision-making, and access control.

About

What this project is about

Cyber Proxy Defender is a knowledge-focused academic project that explains how secure proxy routing can help organizations inspect requests, reduce unsafe access, and keep a record of network activity.

Workflow

How the request moves

User Browser -> Proxy Server -> Website Server -> Proxy Server -> User Browser. This makes it possible to inspect request flow, capture timing, and show complete records inside the dashboard Traffic section.

Project Knowledge

A simple web interface that helps explain secure proxy monitoring in a practical way.

The homepage introduces the idea, the about page explains the flow, and the authentication pages lead users into the protected dashboard experience.

Security Goal

Every request can be checked before it becomes a risk.

By routing traffic through a proxy, the system can inspect the destination, apply filtering rules, and help administrators respond faster to suspicious activity.
